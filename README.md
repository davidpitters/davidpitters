### Fiatium: reliability patterns for payment operations

[Fiatium](https://github.com/davidpitters/Fiatium) is a simulated payment-operations workspace built with React, TypeScript, FastAPI, Python, and SQL Server.

It demonstrates tenant-scoped APIs, immutable double-entry accounting, idempotent payment processing, transactional outbox and inbox patterns, deterministic failure recovery, refunds, and reconciliation workflows—without using real payment credentials or card data.
